# 과제 9 — 나를 말하는 에이전트

리추얼 기록 22일(아침 22 · 마무리 19)을 재료로 나의 강점과 이야기를 찾아 주는
에이전트를 만들고, 그 결과를 내가 고르고 다듬어 자기소개서 초안과
포트폴리오 뼈대를 완성하는 과제입니다.

## 산출물

| 파일 | 역할 |
| --- | --- |
| `narrative.md` | **서사 문서(제출물)** — 고른 대목·에이전트 규칙·강점 지도·3인칭/1인칭 이야기·동료 답·자기소개서 초안·AI와 나의 판단 |
| `index.html` + `styles.css` | **포트폴리오 뼈대(선택 URL)** — 이름·자기소개서·강점 셋과 1~8번 과제 산출물을 강점별로 배치한 한 페이지 |

## 강점 셋 (에이전트가 기록에서 뽑은 것)

1. **쉽게 풀어 알려준다** — 네트워크·코딩·AI 강의까지, 모르는 걸 그 자리에서 풀어주는 장면이 매일 반복
2. **관찰하고 막힌 자리를 채운다** — "주변 관찰"이 거의 매일의 첫 행동, 막힌 조원을 먼저 발견
3. **자리를 지키고 끝낸다** — "지각하지 않는 것"의 매일 반복, 아프고 졸려도 나옴

## 본인이 채우는 자리 (제출 전 필수)

`narrative.md`의 아래 항목은 과제 기준상 본인이 직접 채워야 합니다:

- 1번 표에 "직접 읽으며 표시한 대목" 확인·수정
- 3번 "내가 지운 항목과 이유" 최소 1개
- 4번 고난 장면(연도·장소) → 3인칭 초안 확인 → **1인칭 직접 고쳐 쓰기**
- 4번 동료 두 사람의 답(이름 없이)
- 5번 자기소개서 첫·마지막 문장 직접 작성
- 7번 AI 판단 3줄 확인
